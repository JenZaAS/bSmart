# bCoder

bCoder is the coder role as a small standalone skill. Any agent that writes,
fixes, or refactors code can follow it. bSwarm's coder always does.

Status: draft, optional. Works on its own, with or without a plan. Install it
together with bSwarm, which uses it.

## Files

| File | Purpose |
|---|---|
| `coder.md` | The coder rules. |

## Use

Say "use bCoder for <task>", or follow `coder.md` when you get a plan.
