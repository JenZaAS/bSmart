# bArchitect

bArchitect is the architect role as a small standalone skill. It plans a code
change for a coder and closes it with a final knowledge check. bSwarm's
architect always follows it.

Status: draft, optional. Works on its own, with or without bSwarm. Install it
together with bSwarm, which uses it.

## Files

| File | Purpose |
|---|---|
| `architect.md` | The architect rules and the plan format. |

## Use

Say "use bArchitect to plan <change>". Hand the plan to a coder (bCoder), have
it reviewed (bCritic), then run the final knowledge check in `architect.md`.
