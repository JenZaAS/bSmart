# <topic> index

Top index of a knowledge root (the instance Library or a project's
`knowledge/`). It lists topics only, one line each. Each topic folder has its
own `index.md` that lists its notes. Rules: `bSmart_Protocols/knowledge.md`.

<!-- entries -->
- [code/](code/index.md) - language-agnostic code notes; one subfolder per language, such as code/<language>/
- [tools/](tools/index.md) - apps, services, and external references; one subfolder each
- [general/](general/index.md) - last resort when no better topic fits; move notes out when a topic appears
