# Project workdocs

This folder is for project-local working documents for larger, multi-session, troubleshooting, design, verification, or implementation work.

Use a workdoc when the work is too detailed for `project.md`, spans sessions, or needs a clear handoff trail.

When a workdoc is complete, consider whether any durable lessons should be moved into this project's `library/` folder or the global bSmart Library.

Do not store secrets here.
