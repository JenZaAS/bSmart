# Project knowledge

This folder is for curated, reusable knowledge that belongs to this project specifically.

Keep the two knowledge classes separate:

- `general/` — file-independent project/domain concepts, decisions, relationships, invariants, and reusable facts.
- `code/` — concise source-specific or codebase-navigation notes, including items created by `create bKnowledge {filename}`.

Use it for:
- project-specific references and guides
- summaries that should be reused later
- templates or examples useful inside this project
- cleaned-up lessons from workdocs or research
- context that helps an AI or human understand this project later

Use `workdocs/` for active working notes, investigations, and handoffs. Use the global bSmart Library instead when the material is broadly useful across projects or across the whole bSmart instance.

This folder is named `knowledge/` rather than `library/` to avoid confusion with software libraries in coding projects.

Do not store secrets here.
